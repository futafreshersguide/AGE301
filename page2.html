Measures of Central Tendency

Central tendency describes the "center" or "typical" value of a dataset. The three main measures are the Mean, Median, and Mode.

1. The Mean (Arithmetic Average)

The sum of all values divided by the number of values. It is highly affected by outliers.

  • Ungrouped Data:
    x̄ = (Σx) / n
  • Grouped Data:
    x̄ = (Σfx) / (Σf)
    Where x is the class midpoint.
  • Assumed Mean Method (Shortcut):
    x̄ = A + [(Σfu) / Σf] × c
    Where A = Assumed mean, u = (x - A)/c, and c = class width.

2. The Median

The exact middle value when data is arranged in ascending or descending order. It divides the distribution into two equal halves.

  • Ungrouped Data: If n is odd, it's the middle term. If n is even, it's the average of the two middle terms.
  • Grouped Data: First, find the median class where the cumulative frequency (N/2) falls.
    Median = Lm + [ ( (N/2) - CFb ) / fm ] × c
    Where:
    Lm = Lower class boundary of the median class
    N = Total frequency (Σf)
    CFb = Cumulative frequency strictly before the median class
    fm = Frequency of the median class
    c = Class width

3. The Mode

The value that appears most frequently in a dataset.

  • Ungrouped Data: Simply count which number appears the most.
  • Grouped Data: First, identify the modal class (the class with the highest frequency).
    Mode = Lmo + [ Δ1 / (Δ1 + Δ2) ] × c
    Where:
    Lmo = Lower class boundary of the modal class
    Δ1 = Frequency of modal class minus frequency of the class before it
    Δ2 = Frequency of modal class minus frequency of the class after it
    c = Class width
AGE 301 Exam Hint: Class Limits vs. Boundaries!
If your table gives intervals like 45-54, 55-64, there is a gap. You MUST use boundaries (e.g., 44.5-54.5, 54.5-64.5) for calculating Lm, Lmo, and the class width (c). In this example, c = 54.5 - 44.5 = 10, NOT 9!

Measures of Dispersion (Spread)

Dispersion tells us how scattered or spread out the data points are around the center. A small dispersion means the data is tightly clustered; a large dispersion means it is widely spread.

1. Mean Deviation

The average of the absolute differences between each data point and the mean.

  • Ungrouped Data:
    MD = Σ|x - x̄| / n
  • Grouped Data:
    MD = Σf|x - x̄| / Σf

2. Variance (s² or σ²)

The average of the squared differences from the mean.

  • Ungrouped Data:
    Variance = Σ(x - x̄)² / n
  • Grouped Data (Standard Formula):
    Variance = Σf(x - x̄)² / Σf
  • Grouped Data (Shortcut Formula - Recommended!):
    Variance = [ Σfx² / N ] - (x̄)²
    Where N = Σf. This shortcut saves you from dealing with messy decimals in the (x - x̄) column.

3. Standard Deviation (s or σ)

The square root of the variance. It is the most widely used measure of spread because it brings the units back to the original units of the data.

SD = √(Variance)
AGE 301 Exam Hint: Σfx² vs (Σfx)²
Do not confuse these two!
- Σfx² means you square the x value first, then multiply by f, then sum them up.
- (Σfx)² means you sum the fx column first, and then square the final total.
Using the shortcut variance formula carefully will save you serious time in the exam hall!

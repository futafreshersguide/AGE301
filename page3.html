Discrete Random Variables

A discrete random variable X takes on a countable number of distinct values. The probability distribution function (pdf) or probability mass function assigns a probability P(X=x) to each possible value.

Core Property

The sum of all probabilities in a valid distribution must equal exactly 1.

Σ P(X = x) = 1
Exam Hint: Finding Constants!
If an exam question gives you a pdf like P(X = x) = a(3/4)x and asks you to find 'a', simply set up the equation to sum to 1. This often forms an infinite geometric progression where S∞ = a / (1 - r).

Expectations and Variances

The "Expected Value" is the long-run average of the random variable. It is synonymous with the Mean (μ).

1. Expected Value, E(X)

E(X) = Σ [x × P(X = x)]

Properties of Expectation:

  • E(c) = c (The expectation of a constant is the constant itself)
  • E(cX) = c × E(X)
  • E(cX + b) = c × E(X) + b
  • E(X²) = Σ [x² × P(X = x)]

2. Variance, Var(X)

Variance measures the spread of the random variable around its expected value.

Var(X) = E(X²) - [E(X)]²

Properties of Variance:

  • Var(c) = 0 (A constant does not vary!)
  • Var(cX) = c² × Var(X) (Constants pulled out of variance are squared)
  • Var(cX + b) = c² × Var(X) (Adding a constant shifts the distribution but doesn't change its spread)

The Binomial Distribution

Used when there are a fixed number of independent trials (n), and each trial has only two possible outcomes: Success (p) or Failure (q). Note that p + q = 1.

P(X = x) = nCx × px × qn-x
  • Mean (μ): E(X) = np
  • Variance (σ²): Var(X) = npq
  • Standard Deviation (σ): SD = √(npq)
AGE 301 Frequent Proofs:
You are often asked to prove properties of the Binomial random variable. Remember these established identities:
1. E[X²] = npq + μ²
2. E[X(X-1)] = npq + μ² - μ (Because E[X(X-1)] = E[X² - X] = E[X²] - E[X])
Exam Hint: "At Most" and "At Least"
- "At most 2" means P(X ≤ 2) = P(0) + P(1) + P(2).
- "At least 3" means P(X ≥ 3). If n=5, this is P(3) + P(4) + P(5). Or use the complement: 1 - [P(0) + P(1) + P(2)].

The Poisson Distribution

Used for modeling the number of times an event occurs in an interval of time or space. It is also used as an approximation to the Binomial distribution when n is very large and p is very small (where λ = np).

P(X = x) = (e-λ × λx) / x!
  • Mean (μ): E(X) = λ
  • Variance (σ²): Var(X) = λ

(Notice that in a Poisson distribution, the mean and variance are equal!)

Conditions for using Poisson Distribution:

(Frequently asked theory question worth 4 marks)

  1. The events occur randomly and independently of one another.
  2. The average rate (mean) of occurrence (λ) over a given interval is known and constant.
  3. Two events cannot occur at exactly the same instant.
  4. The probability of an event occurring in a small interval is proportional to the length of the interval.

Applications of the Poisson Model:

  • Modeling the number of misprints on a page of a book.
  • Predicting the number of machine breakdowns in a factory during a specific shift.
  • Estimating the number of customers arriving at a service counter per hour.
  • Counting the number of defects found in a continuous length of manufactured wire.

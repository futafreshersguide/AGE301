Correlation vs. Regression

While often taught together, they serve different purposes:

  • Correlation measures the strength and direction of the linear relationship between two variables. (Does X increase when Y increases?)
  • Regression creates a mathematical model (an equation) to predict the value of a dependent variable (Y) based on an independent variable (X).

The Big Confusion: Capital X, Y vs. Small x, y

In AGE 301, many students lose marks because they confuse the raw data with the deviations. Here is the golden rule:

Capital X and Y (Raw Data)

These are the exact numbers given to you in the exam question table.
Example: X = 10, Y = 50.

Small x and y (Deviations from the Mean)

Small letters represent the difference between the raw data and their average (mean).
x = X - X̄ (Raw X minus Mean of X)
y = Y - Ȳ (Raw Y minus Mean of Y)

Why does this matter? Because the formulas for Sum of Squares (SS) are much simpler to write using small letters:

  • SSXX = Σ(X - X̄)² = Σx²
  • SSYY = Σ(Y - Ȳ)² = Σy²
  • SSXY = Σ(X - X̄)(Y - Ȳ) = Σxy
Exam Shortcut: Calculating small x and y for every row is tedious and prone to rounding errors. Use the computational formulas with Capital X and Y instead!

Computational Formulas (Use these in the exam!):
SSXX = ΣX² - [(ΣX)² / n]
SSYY = ΣY² - [(ΣY)² / n]
SSXY = ΣXY - [(ΣX)(ΣY) / n]

Pearson Correlation Coefficient (r)

This value ranges from -1 to +1.
+1 is a perfect positive correlation, -1 is a perfect negative correlation, and 0 means no linear correlation.

r = SSXY / √(SSXX × SSYY)

Coefficient of Determination (r²)

This tells you the percentage of variance in the dependent variable (Y) that is explained by the independent variable (X). If r = 0.9, then r² = 0.81 (or 81%).

Three Approaches to Regression

Regression finds the "Line of Best Fit." http://googleusercontent.com/image_content/307 The equation is usually written as: Ŷ = a + bX (or Ŷ = β0 + β1X).

1. The Statistical / Formula Approach (Simple Linear Regression)

Used when you have only ONE independent variable (X).

  • Step 1: Find the Slope (b or β1)
    b = SSXY / SSXX
  • Step 2: Find the Y-Intercept (a or β0)
    a = Ȳ - b(X̄)

2. The Simultaneous Equation Approach (Multiple Linear Regression)

Used when you have multiple independent variables (e.g., X1, X2) like in the 2024/2025 AGE 301 exam. The model is Ŷ = b0 + b1X1 + b2X2.

You must construct and solve these three "Normal Equations" simultaneously:

1) nb0 + b1ΣX1 + b2ΣX2 = ΣY
2) b0ΣX1 + b1ΣX1² + b2ΣX1X2 = ΣX1Y
3) b0ΣX2 + b1ΣX1X2 + b2ΣX2² = ΣX2Y

Hint: Create a large table to find all these sums (Σ), plug them into the equations, and solve using substitution, elimination, or your scientific calculator's equation solver.

3. The Matrix Approach

An advanced, elegant way to solve multiple regression without messy simultaneous equations. It uses matrices to find the coefficients vector B (which contains b0, b1, b2, etc.).

B = (XTX)-1 XTY

Where:
X is the matrix of independent variables (with a column of 1s for the intercept).
Y is the column vector of the dependent variable.
XT is the transpose of the X matrix.
(XTX)-1 is the inverse of the multiplied matrices.
